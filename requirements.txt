# What the newsroom actually imports.

#   python3 -m pip install -r requirements.txt
#
# This Mac's python3 is externally managed (PEP 668), which is how Pillow and
# numpy already got there. Same flag for anything new:
#
#   python3 -m pip install --break-system-packages -r requirements.txt
#
# Or, cleaner, if you ever want the environment isolated from macOS:
#   python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
#
# Lower bounds, not pins, with one exception. Pillow and libraqm decide how
# Kannada conjuncts rasterise, so a bump moves the golden fingerprints without
# anybody touching this repo. PROVENANCE.json records the versions that made
# each render, which is how a golden failure can say WHY and not only THAT.

# ── Line A: the daily package. Required. ─────────────────────────────────────

numpy>=1.26             # grades, grain, scrims, the editorial plate
fonttools>=4.40         # reads which letters each face can set. Without it the
                        # empty-box guard (TYPE-01) silently switches off (D114).
edge-tts>=6.1           # the narration fallback when Google TTS is down (D53,
                        # D110). Gemini TTS is called over plain HTTPS, no SDK.

# Nothing fetches news (D92): no scraper, no extraction model. The editor's
